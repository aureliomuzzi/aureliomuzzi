# 👽 Aurélio Muzzi

😎 Tenho 48 anos e sou natural de Manaus, Amazonas. Sou formado como Técnico em Desenvolvimento de Sistemas para Internet pelo SENAC e Tecnólogo em Sistemas de Telecomunicações pelo Instituto Federal do Amazonas (IFAM – CMDI).

Atuo na área de desenvolvimento de sistemas, com experiência no desenvolvimento e manutenção de aplicações web e sistemas personalizados.

Atualmente, continuo aprimorando meus conhecimentos em desenvolvimento de software e novas tecnologias, com foco na evolução profissional e no desenvolvimento de soluções para diferentes necessidades.

Para conhecer mais sobre minha trajetória profissional, acesse meu LinkedIn: [Aurélio Muzzi](https://www.linkedin.com/in/aureliomuzzi/).
